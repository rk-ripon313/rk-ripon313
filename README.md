## 🌟 Featured Projects

### 🩸 [BondhOn - Civic Action & Emergency Coordination Platform](https://github.com/rk-ripon313/bondhon)

A full-stack civic platform designed to connect people and coordinate community support during emergencies. Focused on blood donation, community events, and location-based assistance.

**My Role:** Full-stack development, UI/UX implementation, database integration, authentication, and feature development.

**Key Features:**

- Blood request creation, tracking, and donor coordination
- Donor directory with blood group and location-based filters
- Community event creation, participation, and management
- Google and credentials-based authentication
- Location-based discovery and distance-aware features
- Notification system with polling and sound alerts
- User profiles, following, blocking, and privacy controls
- Weather information based on location

**Tech Stack:** Next.js, React, TypeScript, Tailwind CSS, MongoDB, Mongoose, Auth.js, Cloudinary

**Source Code:** [GitHub Repository](https://github.com/rk-ripon313/bondhon)

**Live Demo:** [BondhOn Live](https://bondhon.vercel.app/)

**Learning / Challenges:** Developed a location-aware application involving authentication, database relationships, server-side operations, and complex user interactions.

### 🏫 [Edu-Nest - Educational Platform](https://edu-nest-edu.vercel.app/)

A full-stack **learning management system (LMS)** for students and educators with responsive UI and smooth navigation.

**My Role:** Frontend developer, responsible for UI/UX, responsive design, and component architecture.

**Key Features:**

- Multi-role authentication: Student and Educator with Google and Credentials login
- Secure payment integration with Stripe
- Students can purchase and access PDF books and video courses with progress tracking
- Centralized "My Learning" dashboard for enrolled content
- Educator dashboard for content CRUD and publishing
- Drag-and-drop chapter and lesson reordering
- Resume playback, completion indicators, and progress-based learning

**Tech Stack:** Next.js, React, MongoDB, NextAuth, Tailwind CSS, Stripe, Resend, Cloudinary

**Source Code:** [GitHub Repository](https://github.com/rk-ripon313/Edu-Nest)

**Live Demo:** [Edu-Nest Live](https://edu-nest-edu.vercel.app/)

**Learning / Challenges:** Implemented role-based access control (RBAC) and optimized responsive multi-page layouts.
